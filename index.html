TROUBLESHOOTING

How I approach network problems

01

Identify

Understand the symptom, affected users, VLAN/subnet and scope of the outage.

02

Check Layer 1/2

Verify interfaces, cabling, VLAN membership, trunks, STP and EtherChannel.

03

Check Layer 3

Verify IP addressing, gateway, routing table, ARP and reachability.

04

Fix & Verify

Apply the smallest safe change, test end-to-end and document the root cause.

CASE STUDY

DHCP clients not receiving an IP address

Checks: VLAN → trunk → SVI → DHCP scope → relay/helper address → client lease.

Verification: show vlan brief · show interfaces trunk · show ip interface brief · show ip dhcp binding
